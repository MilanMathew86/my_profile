# Portfolio Website (scaffold)

This is a minimal, professional portfolio scaffold built with HTML, CSS, and JavaScript.

Quick preview:

Windows (open in default browser):

```powershell
start index.html
```

Or use a simple static server (recommended):

```powershell
# Install if needed: npm i -g serve
serve -s . -l 5000
```

Next steps:
- Replace copy in `index.html` with your real bio, project descriptions, and links.
- Swap the profile image URL with your photo in the project folder.
- Hook the contact form to an email service or backend endpoint.
